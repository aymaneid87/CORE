# ميزان — إدارة مشاريع التشطيبات + نظام المقايسات

## التشغيل لأول مرة

1. في Supabase → SQL Editor شغّل الملفات بالترتيب:
   1. `supabase/schema.sql` (المشاريع والمعاملات)
   2. `supabase/002_estimation.sql` (الكتالوج، الأسعار، المقايسات)
   3. `supabase/003_seed_catalog.sql` (التصنيفات + منتجات تجريبية)
   4. `supabase/004_price_sources.sql` (المناطق، مصدر السعر، الأسعار المرجعية)
   5. `supabase/005_seed_bulletin_2026_06.sql` (أسعار نشرة يونيو 2026)
   6. `supabase/006_bulletin_imports.sql` (استيراد النشرات بالذكاء الاصطناعي)
2. `.env.local`:
   ```
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   ANTHROPIC_API_KEY=...   # لقراءة نشرات الأسعار (سيرفر فقط — ما يتحطش NEXT_PUBLIC)
   ```
3. `npm install && npm run dev`

## النسخة التجريبية (من غير Supabase ولا سيرفر)
- `npm run build:demo` بيبني `dist/mizan-demo.html`: صفحة واحدة فيها نفس الشاشات ونفس محرك المقايسة.
- البيانات بتتحفظ في المتصفح (`demo/local-db.js` بيحاكي أوامر Supabase اللي الشاشات بتستخدمها)، ومعاها شقة تجريبية جاهزة.
- استيراد النشرات بالذكاء الاصطناعي مش متاح فيها (محتاج سيرفر ومفتاح API).
- هوية الشركة (الاسم/الشعار/التواصل) في `lib/brand.js`، والألوان في `app/globals.css`.

## هيكل نظام المقايسات

| الملف | الدور |
|---|---|
| `lib/estimation/geometry.js` | حصر الكميات من الأبعاد: أرضيات، حوائط صافية بخصم الفتحات، تجليد لارتفاع معيّن، وزرة، عزل |
| `lib/estimation/categories.js` | تصنيفات الخامات والمصنعيات (وحدة التسعير، وحدة الحصر، نسبة الهالك) |
| `lib/estimation/templates.js` | شجرة اختيارات التشطيب (البنود ← الأسئلة ← الاختيارات ← المكوّنات تأسيس/تشطيب) |
| `lib/estimation/engine.js` | المحرك: اختيارات + كتالوج ← بنود وكميات وتكلفة وقائمة مشتريات مجمّعة |
| `lib/estimation/sample-products.js` | **أسعار تقديرية من السوق المصري (سبتمبر 2026)** بثلاث فئات: اقتصادي / متوسط / فاخر — هي الأسعار الافتراضية |
| `scripts/generate-seed.mjs` | بيولّد `003_seed_catalog.sql` من الكود — `npm run seed:generate` |
| `tests/` | اختبارات بقيم محسوبة يدوياً — `npm test` |

### قواعد الدقة
- الارتفاع إلزامي لكل فراغ، ومفيش فتحة تعدّي السقف.
- الفتحات بتتخصم من التجليد والدهان حسب منسوبها (شباك فوق خط التجليد مش بيتخصم من السيراميك).
- الأوجه والهالك بيتحسبوا على الخامات بس، مش المصنعيات.
- التقريب لعبوات كاملة (كراتين/بستلات) بيتم على إجمالي الوحدة، مش لكل غرفة.
- أي منتج ناقص أو من غير سعر ← المقايسة "غير مكتملة" ومينفعش تتعتمد. مفيش تسعير صامت بصفر.
- الأسعار سجل تاريخي (كل تحديث صف جديد)، والنسخة المعتمدة من المقايسة بتجمّد الأسعار والكميات.

## الأسعار التقديرية وتعديلها
- الأسعار الافتراضية تقديرية (سبتمبر 2026)، مبنية على أسعار معارض وتجار منشورة + نشرة يونيو للمصنعيات والسيراميك والرخام. غير شاملة الضريبة.
- المقايسة بتطلّع تنبيه واحد: عدد المنتجات بأسعار تقديرية ونسبتها من التكلفة — عشان تأكدها من المورد قبل عرض السعر على العميل.
- **تعديل سعر منتج**: الكتالوج ← «تحديث السعر». **تعديل مجموعة كاملة بنسبة**: الكتالوج ← المجموعة ← «تعديل أسعار المجموعة بنسبة %».
- كل تعديل بيتسجّل كسعر جديد بتاريخه للشركة بس، وسعر الشركة بيغلب التقديري. الأسعار القديمة بتفضل في السجل والمقايسات المعتمدة مش بتتأثر.
- أسعار نشرة يونيو موجودة كبدائل في الكتالوج (مش افتراضية) وكمرجع لمقارنة تكلفة الدهانات.

## نشرات الأسعار
- `lib/estimation/bulletins/2026-06.js`: البنود الخاصة بالتشطيبات من "متوسطات أسعار مواد البناء — تحديث يونيو 2026"، منقولة من الـ PDF ومع كل بند رقم الصفحة.
- البنود اللي ليها نفس وحدة الحصر (م²، م.ط) بتدخل الكتالوج كمنتجات عامة، وأسعار القاهرة منفصلة عن الصعيد.
- البنود المركّبة (توريد وعمل دهانات بلاستيك) بتُستخدم كسعر مرجعي، والمقايسة بتنبّه لو الفرق أكتر من ±25%.
- الأسعار غير شاملة الضريبة.
- **استيراد نشرة جديدة من الواجهة**: الكتالوج ← «استيراد نشرة أسعار (PDF)»:
  1. المتصفح بيقسم الـ PDF لصفحات، وكل صفحة بتتبعت لـ `/api/bulletins/extract`.
  2. السيرفر بيقرا الصفحة بـ Claude **مرتين مستقلتين** (`lib/bulletin-import/extract.js`) — أي اختلاف في سعر أو سطر ناقص بيتعلّم ولازم يتأكد يدوياً.
  3. التصنيف: المطابقات المحفوظة أولاً، وبعدها اقتراح الذكاء الاصطناعي (بيتعلّم للمراجعة). الوحدة لازم تطابق وحدة التصنيف وإلا الاعتماد يترفض.
  4. الاعتماد بدالة `approve_bulletin_import` في قاعدة البيانات: كل الأسعار تتسجّل أو ولا واحد، والمطابقات تتحفظ للنشرة الجاية.
  - تنبيه لو السعر اتغيّر أكتر من 30% عن آخر نشرة.
  - **اختبار دقة القراءة على ملف حقيقي**: `ANTHROPIC_API_KEY=... npm run verify:bulletin -- <ملف.pdf>` — بيقرا الصفحات بنفس كود السيرفر ويقارن بالـ 31 بند المنقولين يدوياً من نشرة يونيو.
  - الأسماء القصيرة الملتبسة (زي «جلالة عادة» اللي موجودة تحت الترابيع وتحت الدرج) ما بتتطابقش بالاسم لوحده.

## المراحل الجاية
1. **استيراد قوائم أسعار الموردين** (Excel/CSV) كمسودة ← مراجعة ← اعتماد.
2. **قراءة الرسومات 2D بالذكاء الاصطناعي**: رفع صورة المسقط ← استخراج الفراغات والأبعاد والفتحات ← مراجعة المستخدم وإدخال الارتفاع.
3. بنود إضافية: الكهرباء (نقاط/لوحات)، النجارة والأبواب، الألوميتال، التكييف.
4. تصدير المقايسة PDF/Excel بشعار الشركة.
