# CORE IPTV — تطبيق IPTV لتلفزيونات LG webOS

واجهة حديثة بهوية **CORE** (خط Cairo للعناوين + Tajawal للنص، ألوان Teal / Copper / Cream) تعمل بحساب **Xtream Codes**
(الرابط + اسم المستخدم + كلمة المرور) أو برابط قائمة **M3U**. بدون أي مكتبات خارجية عدا `hls.js` (مضمَّن للاختبار على الكمبيوتر فقط؛ التلفاز يشغّل HLS محليًا).

## المميزات
- **تسجيل الدخول:** يقبل `host:port` أو رابط `player_api.php` / `get.php?username=…&password=…` (يستخرج اليوزر والباسورد تلقائيًا) أو رابط `.m3u`. حفظ عدة حسابات والدخول التلقائي.
- **البث المباشر:** فئات + قنوات (قوائم مُجزّأة تتحمل آلاف القنوات) + معاينة ودليل البرامج (الآن/التالي). تنقّل بين القنوات بالأسهم أو CH+/CH−، وقائمة قنوات جانبية أثناء المشاهدة.
- **الأفلام والمسلسلات:** شبكة ملصقات، صفحة تفاصيل (قصة، تقييم، طاقم)، مواسم وحلقات، **استئناف** من آخر نقطة، وتشغيل تلقائي للحلقة التالية.
- **المفضلة، آخر ما شاهدته، البحث** (في القنوات/الأفلام/المسلسلات).
- **إعدادات:** صيغة البث (HLS أو MPEG-TS)، إخفاء محتوى البالغين، نسبة العرض، معلومات الاشتراك.
- إذا فشلت صيغة البث المباشر يجرّب التطبيق الصيغة الأخرى تلقائيًا.

## التحكم
| الزر | الوظيفة |
|---|---|
| الأسهم / OK / Back | تنقّل / اختيار / رجوع |
| 🔴 أحمر | الرئيسية (وإغلاق المشغّل) |
| 🟢 أخضر | البث المباشر (وفي المشغّل: نسبة العرض) |
| 🟡 أصفر | إضافة/إزالة من المفضلة |
| 🔵 أزرق | البحث (وفي المشغّل المباشر: تبديل الصيغة) |
| مشغّل مباشر | ▲▼ أو CH± تغيير القناة · OK إظهار المعلومات ثم قائمة القنوات · ◀ قائمة القنوات |
| مشغّل أفلام | ◀▶ ±10 ث · ⏩⏪ ±30 ث · OK/تشغيل/إيقاف مؤقت |

## التثبيت
```bash
npm i -g @webos-tools/cli
./scripts/package.sh
ares-install --device tv dist/com.core.iptv_1.0.0_all.ipk
ares-launch  --device tv com.core.iptv
```
(إعداد وضع المطور وربط التلفاز بـ `ares-setup-device` مشروح في README التطبيق الإسلامي `../webos-islamic-launcher`.)

## التجربة على الكمبيوتر بدون اشتراك
```bash
node tools/mock-xtream.js     # خادم Xtream تجريبي: http://localhost:8099  (demo / demo)
# افتح index.html في Chrome (للتجربة المحلية شغّل Chrome بـ --disable-web-security) وسجّل الدخول بالبيانات أعلاه
```

## ملاحظات مهمة
- **CORS:** التطبيق يطلب بيانات الخادم مباشرة من جهاز التلفاز. أغلب خوادم Xtream تعمل، وإن رفض خادمك الطلب فستظهر رسالة «تعذر الاتصال». لم أستطع اختبار ذلك مع خادم حقيقي.
- **لم أختبره على تلفاز فعلي:** اختُبر في Chrome مع خادم تجريبي (الدخول، الشاشات، تشغيل HLS)، وبُني IPK بنجاح. جودة التشغيل الفعلية (الصيغ، الترميز، AC3) تعتمد على موديل التلفاز والخادم.
- كلمة المرور تُحفظ في تخزين التطبيق المحلي على التلفاز بنص عادي (لا يوجد قفل نظام لهذا).
- البحث يحمّل القائمة الكاملة للقسم مرة واحدة في الجلسة؛ قد يستغرق ثوانٍ مع القوائم الضخمة.
- التطبيق عميل للعرض فقط ولا يتضمن أي قنوات أو محتوى. استخدمه مع اشتراك تملك حق استخدامه.
- الألوان والخطوط في `css/style.css`، وأيقونات الواجهة SVG مضمّنة (لا تعتمد على خط الإيموجي).
